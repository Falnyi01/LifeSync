
# LifeSync 📚⌚📊
### Your College Life, All in One Place!

## About the Project

**LifeSync** is a web application designed to help college students organize their academic and personal responsibilities in one place.

The idea came from my experience as a college student trying to manage classes, assignments, work schedules, and personal finances using different tools and spreadsheets.

LifeSync aims to simplify student life by bringing these responsibilities together in one organized dashboard.

## Planned Features

- 📚 **Semester & Class Management:** Organize semesters, classes, and schedules.
- ✅ **Assignment & Task Tracking:** Manage assignments, deadlines, and personal tasks.
- 📅 **Calendar & Time Tracking:** View schedules and track work and study hours.
- 💰 **Budget Management:** Track income, expenses, and monthly budgets.
- 📊 **Dashboard & Analytics:** View summaries of academic activities and finances.
- 🔐 **User Accounts:** Create an account and securely access personal information.
